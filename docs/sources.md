# Prior art and sources

- Microsoft Phone Link: QR + Bluetooth pairing, iMessage + SMS on Windows 11, but no group chats, no attachments, recent conversations only: https://www.ghacks.net/2026/06/08/microsoft-phone-link-adds-apple-messages-support-for-windows-with-group-chat-and-attachment-limitations/ and https://support.microsoft.com/en-us/windows/apps/phonelink/troubleshooting-for-messages-in-the-phone-link
- iphonebridge (first open Mac-free iMessage bridge, archived into BlueFerry, MAP limits documented): https://github.com/gabrielmeir53/iphonebridge
- Tether (MIT, Linux + iPhone continuity, Bluetooth + Wi-Fi, mTLS): https://github.com/zackb/tether and analysis at https://www.solosoft.dev/post/tether-imessage-linux-iphone/
- iOS 26.5 EU interoperability changes: https://www.macrumors.com/2026/05/11/ios-26-5-eu-third-party-wearable-changes/
- Apple ANCS spec: https://developer.apple.com/library/archive/documentation/CoreBluetooth/Reference/AppleNotificationCenterServiceSpecification/Introduction/Introduction.html
- BlueBubbles install + docs: https://bluebubbles.app/install/ and https://docs.bluebubbles.app/server/developer-guides/rest-api-and-webhooks
- BlueBubbles vs AirMessage architecture comparison: https://missblue.dev/blog/bluebubbles-vs-airmessage
- Example third-party API client: https://github.com/mdunlap/WearBubbles
